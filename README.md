# Aviation-project
Расчет и визуализация избыточного давления ударной волны (N-волны) от сверхзвукового летательного аппарата на поверхности Земли.  Проект позволяет моделировать "след ударной волны" при сверхзвуковом полете. В основе расчетов лежит АВТОРСКАЯ ФОРМУЛА для оценки избыточного давления, учитывающая параметры самолета и атмосферы.
