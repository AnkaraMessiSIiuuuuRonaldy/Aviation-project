# Aviation-project

Расчет и визуализация избыточного давления ударной волны (N-волны) от сверхзвукового летательного аппарата на поверхности Земли.  

Проект позволяет моделировать "след ударной волны" при сверхзвуковом полете. В основе расчетов лежит АВТОРСКАЯ ФОРМУЛА для оценки избыточного давления, учитывающая параметры самолета и атмосферы.

Расчетные значения, полученные по АВТОРСКОЙ ФОРМУЛЕ, были сопоставлены с экспериментальными данными по избыточному давлению ударных волн от реальных сверхзвуковых самолетов. Установлено отличное соответствие (отклонение в пределах 1-3 %). Это подтверждает адекватность предложенной модели.

Как это работает:
1. Аналитическая модель: На основе теории ударных волн получена упрощенная формула для максимального избыточного давления под центром следа.
2. Расчет следа: Определяется ширина зоны опасности в зависимости от высоты и числа Мах, где за опасное давление берется значение превышающее 90 Па.
3. Визуализация: Отображение значения давления  в центре.
